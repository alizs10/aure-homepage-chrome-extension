# Aure Homepage v0.3.0

Aure Homepage v0.3.0 introduces one-click **Site Routines**, a redesigned **Setup Wizard** with real-time live previews and backup restoration, accent-tuned **Solid Color Background Presets**, a live **Ping Latency Badge** in the header, smarter search history and ranking, refined clear glass styling, and key reliability fixes across Firefox and Chrome.

## What's New

### Site Routines & Quick Website Picker

- **Grouped Site Routines**: Bundle up to 5 websites into a single Routine shortcut and open all of them together in new tabs with one click. You can create, reorder, edit, and toggle Routines directly from Bookmarks settings.
- **Existing Website Picker**: When adding sites to Favorites, Folders, or Routines, quickly pick from your already-saved Favorites, Folders, Routines, or Top Sites with source filters instead of entering details manually.

### Redesigned Setup Wizard

- **Welcome & Instant Restore**: First-time setup now opens with a clear choice to create a new profile or restore an existing `.json` backup file right away.
- **Live Appearance Preview**: Preview theme, wallpaper, brightness, blur, accent color, and UI glass blur changes in real time while setting up your workspace.
- **Dedicated Search & Privacy Steps**: Choose your default search engine and review privacy and optional browser permissions in clean, focused steps.

### Solid Color Background Presets

- **8 Dual-Mode Solid Themes**: Added 8 accent-tuned solid color background presets, each automatically adapting between light and dark themes.

### Live Ping Latency Badge

- **Connection Speed at a Glance**: The Network Status header widget now displays a color-coded round-trip ping latency badge (in milliseconds) alongside your online and IP status.

## Improvements

### Smarter Search Suggestions & Icons

- **Recent History on Focus**: Focusing an empty search bar now surfaces your 5 most recent browser history visits at the top for quick recall.
- **Best-Match Ranking**: As you type, suggestions across bookmarks, top sites, history, and search engines are ranked by relevance to surface your best matches first.
- **Search Engine Brand Icons**: Added crisp icons for all supported search engines in the Settings and Setup Wizard pickers.

### Refined Clear Glass & Dark Mode

- **Cleaner Clear Glass Surfaces**: Updated cards, headers, sidebars, and inputs with a refined clear glass look featuring smoother light reflections and improved dark mode contrast.

## Fixes

### Pomodoro Notifications & Daily Summary Export

- **Reliable Firefox Alerts**: Improved Pomodoro completion notifications on Mozilla Firefox so repeated session alerts appear reliably without requiring extra permission prompts.
- **No Duplicate Alerts**: Prevented duplicate alarm and completion notifications for the same finished session.
- **Daily Summary Export**: Improved and fixed the exported Pomodoro Daily Summary image so it works cleanly in both Chrome and Firefox.

### Network & Widget Polish

- **More Reliable IP Lookups**: Increased the IP checker timeout to 10 seconds to prevent unnecessary failures on slower connections.
- **Countdown Ring Dashes**: Fixed the countdown circular ring so empty-space ticks render cleanly without overlapping the active progress arc.
- **Notes & Checklists Inputs**: Cleaned up redundant background styling on quick note and checklist input fields.

## Download & Installation

### Google Chrome

1. Download **`aure-homepage-chrome-v0.3.0.zip`** from the Assets section below.
2. Extract the ZIP file.
3. Navigate to `chrome://extensions`.
4. Enable **Developer mode** in the top-right corner.
5. Click **Load unpacked** and select the extracted folder.

### Mozilla Firefox

1. Download **`aure-homepage-firefox-v0.3.0.zip`** from the Assets section below.
2. Extract the ZIP file.
3. Navigate to `about:debugging#/runtime/this-firefox`.
4. Click **Load Temporary Add-on...** and select `manifest.json` from the extracted folder.

## Updating

Download the latest ZIP for your browser from the Assets section below and extract it over your existing installation folder, or reload the unpacked extension in your browser's extensions page. Your personal settings, bookmarks, and widget data are stored locally and will be preserved.
