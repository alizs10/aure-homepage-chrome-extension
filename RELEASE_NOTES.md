# Aure Homepage v0.0.6

This release brings complete real-time cross-tab synchronization across all widgets and settings, alongside major performance, stability, and reliability improvements.

## What's New

* **Real-Time Cross-Tab Sync**: Every change you make now reflects across all open tabs instantly, with no page refresh needed.
  * **Settings & Layout**: Theme colors, display options, and dashboard page arrangements update immediately.
  * **Bookmarks & Folders**: Favorites, folders, and site ordering stay synchronized across all open browser tabs.
  * **Interactive Widgets**: Notes & Tasks, Counters, Progresses, Mood Tracker, Pet House, and Calendar notes update smoothly in real time.
  * **Custom Wallpapers**: Added or selected wallpapers update seamlessly across all open new tabs.

## Improvements

### Performance & Polish

* **Faster & Lighter**: Optimized core architecture for faster startup, smoother transitions, and lower memory usage.
* **Unified Dates**: Standardized date and time formatting across all widgets for a clean, consistent look.

### Background & Alarms

* **Notification Focus**: Clicking a timer notification now smoothly unminimizes and brings your active browser window into focus.

## Fixes

* Prevented search suggestions from unexpectedly reappearing when returning to an open tab.

## Installation

1. Download **aure-homepage-extension-v0.0.6.zip** from the Assets section below.
2. Extract the ZIP file.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted extension folder.

## Updating

1. Download **aure-homepage-extension-v0.0.6.zip** from the Assets section below.
2. Extract the ZIP file.
3. Open `chrome://extensions`.
4. Click **Load unpacked**.
5. Select the newly extracted extension folder.

Your existing data will be preserved as long as the extension ID remains the same.
