## New Features

### Site Routines & Quick Website Picker

- **One-Click Multi-Site Launch**: Group up to 5 websites into a single Routine shortcut and open them all together in new tabs with one click. Manage Routines and toggle their homepage visibility right from Bookmarks settings.
- **Existing Website Picker**: Easily add sites to Favorites, Folders, or Routines by picking from your already-saved bookmarks, folders, routines, or top sites with quick source filters.

### Redesigned Setup Wizard

- **Welcome & Backup Restore**: Start fresh with a new profile or restore all your bookmarks, widgets, and preferences immediately from an existing `.json` backup file.
- **Live Appearance Preview**: See your theme, wallpaper, brightness, blur, accent color, and UI glass blur update in real time as you customize your setup.
- **Search & Privacy Steps**: Pick your default search engine and manage privacy and optional browser permissions directly during onboarding.

### Solid Color Background Presets

- **Accent-Tuned Solid Colors**: Choose from 8 curated solid color backgrounds with automatic light and dark mode variants.

### Network Ping Latency

- **Live Ping Badge**: The Network Status widget in the header now shows a color-coded round-trip ping latency badge (in milliseconds) alongside your connection status and tooltip.

## Improvements

### Smarter Search Suggestions & Icons

- **Recent History Quick Access**: Focusing an empty search bar displays your 5 most recent browser history visits at the top.
- **Best-Match Ranking**: Typing in the search bar now ranks suggestions across bookmarks, top sites, history, and search engines by best match.
- **Search Engine Icons**: Added dedicated brand icons for all supported search providers in Settings and the Setup Wizard.

### Visual & Clear Glass Polish

- **Clear Glass Styling**: Introduced a cleaner clear glass look across cards, sidebars, headers, and input fields, with smoother highlights and better dark mode contrast.

## Bug Fixes

### Pomodoro Timer & Summary Export

- **Firefox Notification Reliability**: Fixed Pomodoro completion notifications in Mozilla Firefox so repeated alerts appear cleanly without extra permission issues.
- **Alert Deduplication**: Eliminated duplicate notifications when a Pomodoro session finishes.
- **Daily Summary Export**: Improved and fixed the exported Pomodoro Daily Summary image so it works reliably in both Chrome and Firefox.

### Network & Widgets

- **IP Lookup Stability**: Extended the IP checker request timeout to 10 seconds to reduce false failures on slower networks.
- **Countdown Progress Ring**: Fixed dashed background ticks in countdown circles so they only appear cleanly in the remaining empty space.
- **Notes & Checklists Styling**: Removed redundant background gradients from note and checklist input fields for a cleaner look.
