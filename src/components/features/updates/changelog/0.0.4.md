## New Features
- **Introducing Folders**: Group your websites into custom folders for better organization. We provide 2 default folders with Google services and the most used and visited AI websites
- **Pomodoro Widget**: Track focus sessions with the new Pomodoro timer
- **Updates Feature**: In-app changelog with version history and new release indicators
- **Quick Access Button**: Jump directly to Sites & Folders settings from the homepage
- **New Special Backgrounds**: Replaced default wallpapers with premium curated backgrounds

## Improvements

### Sites & Folders
- Users can now enable Top Sites, Favorites, and Folders simultaneously with individual toggles
- Automatic favicon fetching from Chrome for cleaner site icons
- Added browsing history and folder websites to search suggestions
- Command search now properly handles localhost and IP addresses with optional ports and paths

### Network Status
- More intelligent connection detection that verifies actual internet access
- Checks connection status on first render and on manual click
- Moved from footer to header for cleaner design and better accessibility

### UI/UX Refresh
- **New Header**: Redesigned header with improved layout and spacing
- **Liquid Glass Interface**: Enhanced glass morphism effects throughout the app
- **Mood Tracker**: Improved UI with better visual hierarchy
- **Pet House**: Improved interface design with ability to hard delete pets
- **App Layout**: Improved responsive design and spacing across all widgets
- **Performance**: Optimized rendering and reduced unnecessary re-renders

## Bug Fixes
- Fixed various UI inconsistencies
- Resolved search input edge cases
- Improved stability across all widgets
