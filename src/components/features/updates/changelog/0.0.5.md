## New Features

### Organize Pages
- **Drag-and-Drop Widget Placement**: Rearrange your widgets with an intuitive drag-and-drop interface. Grab widgets from available widgets and drop them exactly where you want them.
- **Multi-Page Organization**: Organize your dashboard across multiple pages. Add new pages, delete empty ones, and navigate between them with pagination controls.
- **Smart Swapping**: Drop a widget on an occupied cell to automatically swap or relocate displaced widgets to available spaces on the same page.

### Responsive Design
- **Adaptive Grid Layouts**: Your dashboard now adapts to different screen sizes:
  - **Desktop**: 3 columns × 2 rows
  - **Tablet**: 2 columns × 3 rows
  - **Mobile**: 1 column × 6 rows (stacked layout)
- **Seamless Transitions**: Resize your browser window and watch the grid reflow in real-time while preserving widget order and page count.

### Notes & Tasks Widget
- **Advanced Notes**: You can now mix text paragraphs and tasks in a single note! Just press `Shift + Enter` in the input field to create multi-line entries.
- **Smart Cleanup Tools**: Added a new "Cleanup Data" menu in the Notes & Tasks settings. You can now surgically clear completed tasks, wipe all tasks, remove all notes, or delete everything with a single click.

### Counters Widget
A brand new dashboard widget to track days! Perfect for habits, project deadlines, vacations, and chores.
- **Count Up & Count Down**: Track how long it's been since an event, or how many days are left until one.
- **Recurring Countdowns**: Set up repeating countdowns (e.g., "Water plants every 7 days") and instantly reset them with a single click when completed.

### Progresses Widget
A new dashboard widget to track multi-step goals, habits, and projects.
- **Linear & Free Modes**: Follow a strict step-by-step progression with Prev/Next navigation, or check off tasks in any order.
- **Labels & Filtering**: Organize progresses with custom labels and easily filter them by status (All, Undone, Done) or specific categories.
- **Visual Progress Bars**: Track completion with accent-colored progress bars, deadlines, and priority badges.

### Golden Accent
- **New Golden Accent Color**: Added a bright, shiny Golden accent color with a rich golden appearance.
- **Light & Dark Modes**: The Golden accent is tuned separately for light and dark themes for a luminous appearance while maintaining readable foreground contrast.

## Improvements

### Notes & Tasks Widget
- **Auto-growing Input**: The input field now seamlessly transitions from a single line to a multi-line editor when you need more space.

### General
- **New App Icon**: Refreshed the extension logo with a clean, modern design that looks great in the Chrome toolbar and extensions menu.
