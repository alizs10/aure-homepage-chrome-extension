## New Features

### Organize Pages

* **Drag-and-Drop**: Rearrange your widgets easily with an intuitive drag-and-drop interface.
* **Multi-Page Support**: Organize your dashboard across multiple pages and navigate between them seamlessly.
* **Smart Swapping**: Drop a widget on an occupied space to automatically swap or relocate existing widgets.

### Responsive Design

* **Adaptive Layouts**: Your dashboard now adapts perfectly to Desktop, Tablet, and Mobile screen sizes.

### Notes & Tasks

* **Advanced Notes**: Mix text paragraphs and checkboxes in a single note by pressing `Shift + Enter`.
* **Smart Cleanup**: Easily clear completed tasks, wipe all notes, or reset everything from the settings menu.
* **Auto-growing Input**: The text input now seamlessly expands when you need more space.

### Counters Widget

* **Track Days**: Count up since an event or count down to upcoming deadlines, chores, and recurring habits.

### Progresses Widget

* **Track Goals**: Manage multi-step projects and habits with visual progress bars, deadlines, and custom labels.

### Golden Accent

* **New Theme**: Added a bright, shiny Golden accent color, optimized for both light and dark modes.

## Improvements

### Liquid Glass

* **Refined Design**: Improved the Liquid Glass styling for a cleaner, more balanced look across the interface.

### Pomodoro Widget

* **Cross-Tab Sync**: Timers and tasks now stay perfectly in sync across all open tabs.
* **Header Mini-Timer**: Keep track of active sessions and access quick controls from a compact timer in the header.

### Search System

* **Instant Suggestions**: Search results now appear instantly, with web suggestions streaming in smoothly as you type.
* **Better Navigation**: Improved keyboard navigation and auto-fill for a faster, glitch-free search experience.

### General

* **Auto Updates**: Get notified automatically when a new version is available.
* **New App Icon**: Refreshed the extension logo with a clean, modern design.
* **Custom Toaster**: Replaced the default toast library with a custom Toaster that perfectly matches the app's Liquid Glass design.
* **Better Backups**: Faster data import/export with a cleaner UI. Backup files now include the date and time in the filename.
