## New Features
- **Advanced Notes**: You can now mix text paragraphs and tasks in a single note! Just press `Shift + Enter` in the input field to create multi-line entries.
- **Smart Cleanup Tools**: Added a new "Cleanup Data" menu in the Notes & Tasks settings. You can now surgically clear completed tasks, wipe all tasks, remove all notes, or delete everything with a single click.

## Improvements

### Notes & Tasks Widget
- **Auto-growing Input**: The input field now seamlessly transitions from a single line to a multi-line editor when you need more space.
